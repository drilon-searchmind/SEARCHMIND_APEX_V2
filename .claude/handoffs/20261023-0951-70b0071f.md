# Handoff: Apex redesign (commerce design)

## Mål
Redesign af Apex-dashboardets frontend (Next.js) side for side i commerce-designet (sage, mint og grøn), så Apex' data, funktioner og layout bevares. Alt arbejde ligger på branchen `redesign/commerce-dashboard`.

## Fokus nu
Ecommerce-visningen er færdig og pushet (`6e64049`). Vi venter på, at brugeren vælger næste side.

## Næste skridt
Spørg brugeren, hvilken side der skal redesignes nu (fx service dashboards, config, `/home`, parent-property eller apex-radar), og lav den på samme måde: reference-overblik øverst, Apex-detaljer restylet nedenunder.

## Færdigt
- Dashboard-shell (sidebar og topbar), tokens (`src/styles/commerce-design-tokens.css`) og ny `DESIGN.md`. Den gamle spec er flyttet til `docs/design/DESIGN-minimal-legacy.md`.
- Overview (performance-dashboard): key metrics-blok, ensrettede sektionsrækker, distinkte graffarver, mørk tooltip og popovers.
- Daily overview: hero-række mod samme ugedag sidste uge, spend- og omsætningsgrafer, restylet dag-for-dag-tabel.
- Markets overview: indsigter, omsætningsandel vs. spendandel, donut, scorecard, sammenligningsgraf. Demo-API og preview-route kun for demo-ID'er.
- Pace report: reference-overblik plus Apex' detaljerede pacing.
- P&L: hero, waterfall, marginkort plus Apex' opgørelse og faste udgifter.
- Ecommerce: overblik pr. fane (`ProductOverview`, `CustomerOverview`) plus Apex' katalog og kundemetrikker.
- Alle commits er pushet til `origin/redesign/commerce-dashboard`. `main` er urørt på `eec8596`.

## Mangler
- Resterende sider i migrationstabellen i `DESIGN.md`: service dashboards, config, øvrige tools, `/home`, parent-property og apex-radar.
- Intet er testet med en rigtig, logget ind kunde. Kun demo-preview-routes er verificeret.
- Mulig P&L-datafejl skal bekræftes: kortet med faste udgifter viser bureau, tooling og faste udgifter, men opgørelsen viser 0 kr. for demoperioden. Det er eksisterende logik, ikke ændret i redesignet.

## Beslutninger
- Commit eller push aldrig til `main`. Commit på `redesign/commerce-dashboard`, og push kun når brugeren beder om det.
- Ingen deploy. Start eller genstart ikke dev-serveren (brugeren kører `npm run dev` i Cursor). Verificér mod `localhost:3000`.
- Verificér via `/preview/dashboard/69c5097c84057563ba331cd2/<side>` (demo, intet login) ved 1600px og 390px.
- Grafer med flere metrikker eller kanaler bruger `METRIC_CHART_PALETTE` (distinkte farver uden for brandet), ikke brandets grønne.
- Bevar Apex' data og funktioner. Tilføj reference-overblik øverst, og restyl Apex' detaljer nedenunder.
- Heat-shading kun på ROAS og POAS, skaleret fra laveste til højeste værdi. Mål på 1 kr. tæller som "ikke sat".
- Ingen tankestreger i UI-tekst eller docs. Sætningsstart med stort bogstav i labels. Dansk talformat.
- Turbopack kan servere en forældet version af importeret CSS (`performance-dashboard.css`). Læg sidespecifikke regler i sidens egen CSS.
